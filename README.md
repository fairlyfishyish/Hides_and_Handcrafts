# Hides & Handcrafts

**Hides & Handcrafts** is a Fabric mod that expands Minecraft's hunting and leatherworking systems.

The goal is to make animal hides more useful by introducing new tools, materials, and crafting systems centered around processing hides.

## Features

- Field dressing animals for their hides
- New hide-based materials
- Leatherworking and hide processing
- New tools for harvesting and processing hides
- Custom crafting recipes
- More uses for animal drops

## Requirements

- Minecraft **26.2**
- Fabric Loader
- Fabric API

## Installation

1. Install [Fabric Loader](https://fabricmc.net/use/).
2. Install [Fabric API](https://modrinth.com/mod/fabric-api).
3. Download the latest version of **Hides & Handcrafts**.
4. Place the `.jar` file into your Minecraft `mods` folder.
5. Launch Minecraft using your Fabric installation.

## Development Setup

Clone the repository and import it into your preferred Java IDE.

This project uses **Gradle** and **Fabric Loom**.

### Building

On Windows:

`./gradlew build`

The compiled mod will be placed in:

`build/libs/`

## Development

Hides & Handcrafts is currently in development. Features and mechanics may change as the mod evolves.
